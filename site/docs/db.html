How the database layer is built.

Stack

  • kysely — query builder
  • kysely-sqlite — node:sqlite dialect
  • kysely-codegen — type generation

Type generation

Generates the DB type from the migrated schema with kysely-codegen.

  • Command: pnpm run db:gen
  • Output: core/src/db/schema.ts
  • Excluded: urls_fts* (FTS shadow) and migrations

Migrations

Applies pending migrations and records them in migrations. 

core/src/db/migrations/
├── NNN_name.sql
└── NNN_name.ts     # export up(ctx)
  • No down migrations (forward-only)
