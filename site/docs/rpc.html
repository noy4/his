his · rpc

WebSocket gate for the local archive.

Gates

Applied in order on every upgrade. 

/rpc?token=…
├── path     ≠ /rpc         → socket.destroy()
├── origin   ∉ allow-list   → 403
└── token    ≠ expected     → 403
  • Path: only /rpc upgrades.
  • Origin: http://127.0.0.1:<port> or http://localhost:<port> at the bound port. A missing Origin skips this gate.
  • Token: required on every connection.

Token

Per-launch, carried in the query string.

  • Issue: crypto.randomBytes(32).toString('base64url') at startup
  • Transport: query string, ?token=…
  • Storage: state.json

Bootstrap

The SPA receives the token in the entry HTML.

  • Entry HTML: <script>window.__HIS__={"token":"…"}</script> injected before </head>
  • Dev: the dev server injects the same bootstrap from state
  • Client: appends ?token= when opening the socket
