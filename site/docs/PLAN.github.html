Data shape

RPC history.githubStats のレスポンス。

type GithubStats = {
  totals: {
    visits: number; repos: number; owners: number; items: number
    firstVisit: number; lastVisit: number                         // All time の期間表示
  }
  topRepos:  { owner: string; repo: string; visits: number }[]   // 上位 20
  topOwners: { owner: string; repos: number; visits: number }[]  // 上位 20
  topItems:  {                                                    // 上位 20
    owner: string; repo: string
    kind: 'pull' | 'issue'; number: number
    title: string; url: string; visits: number
  }[]
}

パス解析ルール

パス結果
/:ownerowner のみ加算
/:owner/:repo/**owner + repo 加算
/:owner/:repo/pull/:n/**+ item (pull, n)
/:owner/:repo/issues/:n+ item (issue, n)
/settings /notifications /orgs /search …予約語 → 除外
owner / repo は小文字化して集計。PR/Issue の title は最新訪問の urls.title を採用。

Decisions

パース は JS 側

SQL は github.com の visits 取得のみ。パス分解は TS でテスト可能に保つ。

期間は stats と共通

month?: 'YYYY-MM' の同じ引数規約。範囲計算を共有。

部品は共通化

Dashboard.components から汎用部品を切り出し、両ページで使う。

アイコンは owner アバター

repo / PR / 訪問行すべて github.com/:owner.png。PR/Issue は Octicons バッジを重ねる。Row に icon prop 追加。

Top 行は絞込

Top repos / owners は外部リンクでなく Recent visits のフィルタ。PR/Issue 行は外部リンク。

種別フィルタ

kind: 'all' | 'repo' | 'code' | 'issue_pr'。repo = /:owner/:repo ルートのみ（GithubRef.root）· code = それ以外の repo ページ · issue_pr = PR + Issue（GitHub に倣い Issues 先）。全種別が重ならない。

db.changed 再取得 — 保留

保留中。現状は mount 時と期間切替時のみ取得。Dashboard 側の方針が決まり次第そろえる。
