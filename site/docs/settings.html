Privacy controls for the archive.

Hidden patterns

Matching URLs are hidden from every view and aggregate. 

# host — no slash; also matches subdomains
example.com
*.bank.com
10.0.*

# path glob — slash; matched against the URL with the scheme stripped
github.com/*/pull/*

# scheme pattern — matched against the full URL
https://*.example.com/*

# one per line · lowercased · trimmed · deduped · max 500
# * is the only wildcard; other metacharacters are escaped
  • Storage: settings KV, key hidden_patterns (JSON string[])
  • Materialize: matches go to hidden_urls(url_id); every read excludes them with NOT EXISTS
  • Recompute: on save (all URLs) and on ingest (new URLs)
  • RPC: settings.get / settings.set { hiddenPatterns } → { hiddenPatterns, hiddenCount }

Tables

CREATE TABLE settings (
  key   TEXT PRIMARY KEY NOT NULL,
  value TEXT NOT NULL
);

-- separate from urls to avoid FTS reindex on recompute
CREATE TABLE hidden_urls (
  url_id INTEGER PRIMARY KEY NOT NULL REFERENCES urls(id) ON DELETE CASCADE
);
