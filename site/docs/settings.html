Privacy & sync controls for the archive.

Hidden patterns

Matching URLs are hidden from every view and aggregate. 

# host — no slash; also matches subdomains
example.com
*.bank.com
10.0.*

# path glob — slash; matched against the URL with the scheme stripped
github.com/*/pull/*

# scheme pattern — matched against the full URL
https://*.example.com/*

# one per line · lowercased · trimmed · deduped
# * is the only wildcard; other metacharacters are escaped
  • Storage: settings KV, key hidden_patterns (JSON string[])
  • Materialize: matches go to hidden_urls(url_id); every read excludes them with NOT EXISTS
  • Recompute: on save (all URLs) and on ingest (new URLs)
  • RPC: settings.get / settings.set { hidden_patterns } → { hidden_patterns, hidden_url_count }

Sync targets

Only the listed profiles are synced; an empty list syncs nothing. 

# browser — every profile of that browser
chrome
brave

# browser:profile — one exact profile
chrome:Default
  • Storage: settings KV, key sync_targets (JSON string[])
  • Applied: when runSync gets no explicit targets; CLI --target overrides
  • RPC: settings.get / settings.set { sync_targets }
  • UI: Sources view — a card toggle sets a sync target

Tables

CREATE TABLE settings (
  key   TEXT PRIMARY KEY NOT NULL,
  value TEXT NOT NULL
);

-- separate from urls to avoid FTS reindex on recompute
CREATE TABLE hidden_urls (
  url_id INTEGER PRIMARY KEY NOT NULL REFERENCES urls(id) ON DELETE CASCADE
);
