IMPLEMENTATION PLAN

his insights plan

Turn the GitHub view into a plugin shape, then add YouTube on top of it.

Intent

The GitHub view is a domain classifier + aggregator. Make that generic, register it, then YouTube is a spec — not a copy.

Domain insight

A host filter (SQL prefilter) + a URL→entity classifier. GitHub, YouTube are two instances of the same shape.

Registry, not loader

Specs are compiled in and registered by id. No dynamic import — type-safe, no runtime plugin surface.

The spec

// core/src/features/insights/spec.ts
export interface Classified {
  key: string                             // stable entity key
  kind: string                            // ∈ spec.kinds
  title?: string
}

export interface InsightSpec {
  id: string                              // 'github' | 'youtube'
  urlLikes: readonly string[]             // SQL prefilter · 'https://github.com/%'
  kinds: readonly { value: string; label: string }[]
  classify(url: string): Classified | null
  mergeRoots?(rows: Row[]): Row[]         // optional fold (?tab=…, #readme)
}
