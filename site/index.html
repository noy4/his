Quickstart

Clone the repo, build the UI, and launch the menu bar app.

# clone & install
git clone https://github.com/noy4/his
cd his
pnpm install

# build the web UI
pnpm -C webui run build

# launch the menu bar app
pnpm -C desktop run dev

The app starts the server for you. Your archive lives in ~/.his.
