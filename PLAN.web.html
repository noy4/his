his web plan

Plan for the his WebUI — React + @preact/signals SPA over JSON-RPC.

Roadmap

Mock-first — the layout is built against dummy data until the backend lands. src/api.ts is the seam: views talk to signals and a typed client interface only, so the mock swaps for the real RPC client in one place.
